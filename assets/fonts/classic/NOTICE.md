# Classic theme font kit

The theme uses W95FA, a Windows 95-style recreation distributed here unmodified with
its WOFF2 file and its SIL Open Font License 1.1 notice.

- Source: https://www.dafont.com/w95fa.font
- Archive: https://dl.dafont.com/dl/?f=w95fa
- Bundled license: W95FA-OFL.txt
- The archive has one regular face. Browsers synthesize bold text in the theme.

File provenance is recorded in manifest.json. Keep this notice and the bundled license
with the font file when redistributing it.
